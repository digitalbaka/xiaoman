# 每日小测验

目标：用几道小题帮用户复习一个主题，题目准确、难度适中、解析讲清楚。

1. 确认主题与题量：默认「通识」3 题；用户给出主题（英语单词、历史、编程、AI 基础等）或题量时按用户要求。
2. 出题：每题 4 个选项、只有一个正确答案；题干和选项都要自洽，不要靠文字游戏制造难度。难度从易到难排列。
3. 先只给题目，不要泄露答案；等用户作答后再批改。用户说「直接看答案」时再一次性给出。
4. 批改时每题给出：对错、正确答案、两三句解析（为什么对、常见误区）。全对时加一道进阶题，错两题以上时给一条复习建议。
5. 全程用用户的语言；题目涉及事实时确保准确，不确定就不出这道题。

完成后按用户节奏继续下一轮；用户说结束就停，不要自行加题。
